# .github

Organization-wide files for [tantal-os](https://github.com/tantal-os).

- `profile/README.md`: the organization profile shown on
  github.com/tantal-os.
- `SECURITY.md`, `CONTRIBUTING.md` and the issue forms in
  `.github/ISSUE_TEMPLATE/`: GitHub applies them to every repository in the
  organization that has no file of its own.

A repository overrides any of these by adding its own copy.
