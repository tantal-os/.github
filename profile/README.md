# Tantal

Hardened Android firmware based on GrapheneOS for Pixel devices. It keeps
GrapheneOS protection against outside attacks and adds what GrapheneOS
leaves out on purpose: user choice, deep customization, our own design
language and apps.

Tantal has not been released yet and cannot be installed. It is not
affiliated with the GrapheneOS project.
